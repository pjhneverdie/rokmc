# 테스트에 관하여

보니까 개발 할 때는 테스트를 활발하게 하잖아. 이 떄 TestContainers 사용하면 너무 느리다. 빠릿빠릿하게 확인해야 하는데 편하긴 해도 너무 느려서 오히려 더 불편함.

그래서 개발 단계에서는 그냥 직접 로컬에 직접 mysql test container 띄우는 게 맞는 거 같다.

인메모리 안 쓰는 이유가 
실제 환경이랑 달라서니까 flyway랑 무조건 같이 써야 하는데

개발 하다보면 DDL을 여러 번 수정하게 돼 이때마다 flyway 정석대로 버전파면 이미 배포된 상태가 아닐 때 손해가 막심하지. 귀찮음이.

그래서 싹 미는 경우가 많은데 이거 자동화도 좀 해보고 하자.
